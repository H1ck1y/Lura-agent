# 演示知识库

`01`–`05` 是根据厂家公开资料自行整理的简短中文概述，不是复制全文，不是经过专家审核的完整路亚教材。出处见 `sources.json`，整理日期为 2026-10-02。

仅用于 Phase 3 演示检索、引用和 Agent 路由。没有当地鱼情、法律规则、实时库存或完整产品说明。不要把本库当成所有问题都能回答的知识库，也不要把厂家宣传当作钓获保证。

新增资料时使用 `.md`，在 `sources.json` 中登记文件名、标题和来源 URL，再执行 `index_knowledge.py`。没有公开链接的自有资料可将 URL 设为 `null`。README 和其他项目文档不进入知识索引，只有清单中列出的文件会被索引。
